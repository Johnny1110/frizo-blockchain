🔍 insertIntoLeaf() 完整邏輯分析

📋 函數目的與簽名

func insertIntoLeaf(leaf *MPTNode, path []byte, value []byte) (*MPTNode, error) 目的：向現有的 LEAF 節點插入新的鍵值對 輸入： - leaf: 現有的葉子節點 - path: 新插入的十六進制路徑 - value: 新插入的值 輸出： - 新的節點（可能是 LEAF、BRANCH、或 EXTENSION）

🌳 決策流程圖

計算公共前綴長度
commonLen = commonPrefixLen(leaf.Path, path)
↓
commonLen == len(leaf.Path) && commonLen == len(path)?
YES →
情況1：完全匹配
直接更新葉子節點的值
NO →
情況2：需要分裂
創建分支結構

✅ 情況1：完全匹配 (路徑相同)

條件：commonLen == len(leaf.Path) && commonLen == len(path)
插入前：
leaf.Path = [6,3,6,1,7,4]

leaf.Value = "cat"
插入後：
path = [6,3,6,1,7,4]

value = "feline"

結果：直接更新值
if commonLen == len(leaf.Path) && commonLen == len(path) { leaf.Value = value // 直接更新 return leaf, nil }

🔀 情況2：需要分裂 (路徑不同)

當路徑不完全匹配時，需要創建分支結構。這裡有 4 個子情況：

📌 子情況 2.1：兩個路徑都有剩餘

條件：commonLen < len(leaf.Path) && commonLen < len(path)

原有：
leaf.Path = [6,3,6,1,7,4]
leaf.Value = "cat"
插入：
path = [6,3,6,1,7,2]
value = "car"
commonLen = 5
結果結構： EXTENSION [6,3,6,1,7] └── BRANCH ├── [2] → LEAF [] = "car" └── [4] → LEAF [] = "cat"
處理步驟：
1. 創建 BRANCH 節點
2. 處理原葉子：剩餘路徑 = [4]，在分支索引 4 創建 LEAF [] = "cat"
3. 處理新路徑：剩餘路徑 = [2]，在分支索引 2 創建 LEAF [] = "car"
4. 創建 EXTENSION [6,3,6,1,7] 指向 BRANCH

📌 子情況 2.2：只有原葉子有剩餘

條件：commonLen < len(leaf.Path) && commonLen == len(path)

原有：
leaf.Path = [6,3,6,1,7,4]
leaf.Value = "cat"
插入：
path = [6,3,6,1]
value = "prefix"
commonLen = 4
結果結構： EXTENSION [6,3,6,1] └── BRANCH (value = "prefix") └── [7] → LEAF [4] = "cat"
處理步驟：
1. 創建 BRANCH 節點，值設為 "prefix"
2. 處理原葉子：剩餘路徑 = [7,4]，分支索引 7，創建 LEAF [4] = "cat"
3. 創建 EXTENSION [6,3,6,1] 指向 BRANCH

📌 子情況 2.3：只有新路徑有剩餘

條件：commonLen == len(leaf.Path) && commonLen < len(path)

原有：
leaf.Path = [6,3,6,1]
leaf.Value = "prefix"
插入：
path = [6,3,6,1,7,4]
value = "cat"
commonLen = 4
結果結構： BRANCH (value = "prefix") └── [7] → LEAF [4] = "cat"
處理步驟：
1. 創建 BRANCH 節點，值設為 "prefix" (原葉子的值)
2. 處理新路徑：剩餘路徑 = [7,4]，分支索引 7，創建 LEAF [4] = "cat"
3. 不需要 EXTENSION，直接返回 BRANCH

📌 子情況 2.4：沒有公共前綴

條件：commonLen == 0

原有：
leaf.Path = [6,3,6,1]
leaf.Value = "cat"
插入：
path = [4,2,6,7]
value = "dog"
commonLen = 0
結果結構： BRANCH ├── [4] → LEAF [2,6,7] = "dog" └── [6] → LEAF [3,6,1] = "cat"
處理步驟：
1. 創建 BRANCH 節點
2. 分支索引 6：創建 LEAF [3,6,1] = "cat"
3. 分支索引 4：創建 LEAF [2,6,7] = "dog"
4. 直接返回 BRANCH (沒有公共前綴)

💻 完整代碼實現

func (t *ModifiedMerklePatriciaTree) insertIntoLeaf(leaf *MPTNode, path []byte, value []byte) (*MPTNode, error) { commonLen := commonPrefixLen(leaf.Path, path) // 情況1：完全匹配，直接更新值 if commonLen == len(leaf.Path) && commonLen == len(path) { leaf.Value = value return leaf, nil } // 情況2：需要分裂，創建分支節點 branch := &MPTNode{ NodeType: BRANCH, Dirty: true, } // 處理原葉子節點的剩餘路徑 if commonLen < len(leaf.Path) { branchIndex := leaf.Path[commonLen] remainingPath := leaf.Path[commonLen+1:] if len(remainingPath) == 0 { // 路徑用完，值存在分支節點 branch.Value = leaf.Value } else { // 創建新的葉子節點 branch.Children[branchIndex] = &MPTNode{ NodeType: LEAF, Path: remainingPath, Value: leaf.Value, Dirty: true, } } } else { // commonLen == len(leaf.Path)，原葉子路徑是新路徑的前綴 branch.Value = leaf.Value } // 處理新插入路徑的剩餘部分 if commonLen < len(path) { branchIndex := path[commonLen] remainingPath := path[commonLen+1:] if len(remainingPath) == 0 { // 路徑用完，值存在分支節點 if branch.Value != nil { return nil, errors.New("conflict: both paths end at branch node") } branch.Value = value } else { // 創建新的葉子節點 if branch.Children[branchIndex] != nil { return nil, errors.New("conflict: branch index already occupied") } branch.Children[branchIndex] = &MPTNode{ NodeType: LEAF, Path: remainingPath, Value: value, Dirty: true, } } } // 如果有公共前綴，創建擴展節點 if commonLen > 0 { return &MPTNode{ NodeType: EXTENSION, Path: path[:commonLen], Child: branch, Dirty: true, }, nil } return branch, nil }

🎯 關鍵要點總結

情況 條件 處理方式 返回節點類型
完全匹配 commonLen == len(both paths) 直接更新值 LEAF
兩路徑都有剩餘 commonLen < len(both paths) 創建分支 + 兩個子節點 EXTENSION → BRANCH
原葉子有剩餘 commonLen < len(leaf) && == len(path) 分支節點存新值 + 子節點存原值 EXTENSION → BRANCH
新路徑有剩餘 commonLen == len(leaf) && < len(path) 分支節點存原值 + 子節點存新值 BRANCH
無公共前綴 commonLen == 0 直接創建分支 + 兩個子節點 BRANCH
💡 核心理解：
1. 公共前綴：決定是否需要 EXTENSION 節點
2. 分支索引：公共前綴後的第一個 nibble
3. 剩餘路徑：分支索引後的所有 nibbles
4. 值的位置：路徑用完時存在分支節點，否則創建 LEAF 節點
